# 🏙️ ПОЛНОЕ РУКОВОДСТВО: Запуск системы AqylShahar на Windows (с нуля)

Это руководство создано для того, чтобы любой человек, даже не имеющий навыков программирования, смог запустить этот проект на своем компьютере.

---

## 🏛️ Что это за проект?
**AqylShahar** — это интерактивный дашборд управления городом Алматы. Он использует данные реальных датчиков и искусственный интеллект (ИИ) для анализа чрезвычайных ситуаций.

---

## 💻 0. Системные требования
Для плавной работы (особенно части с ИИ) желательно иметь:
*   **Оперативная память (RAM):** от 8 ГБ (лучше 16 ГБ).
*   **Процессор:** современный (Intel Core i5/i7 или Ryzen 5/7).
*   **Место на диске:** ~10 ГБ (сам проект + нейросеть).
*   **Интернет:** нужен только для первой настройки и скачивания моделей.

---

## 🛠️ ШАГ 1: Установка инструментов (Делается 1 раз)

Вам нужно установить две программы. Без них проект — просто набор текста.

### 1. Node.js (Движок для запуска проекта)
1.  Зайдите на [nodejs.org](https://nodejs.org/en).
2.  Нажмите на большую кнопку слева: **"22.x.x LTS (Recommended for Most Users)"**.
3.  Запустите скачанный файл `.msi`.
4.  В установщике просто жмите **Next** -> **Next**. 
5.  **ВАЖНО:** Когда увидите галочку *"Automatically install the necessary tools"*, поставьте её.
6.  В конце нажмите **Finish**. Если откроется черное окно (PowerShell), нажмите любую клавишу, чтобы оно закрылось или установило доп. компоненты.

### 2. Ollama (Сердце искусственного интеллекта)
Проект использует локальный ИИ, который работает на ВАШЕМ компьютере, а не в облаке.
1.  Зайдите на [ollama.com](https://ollama.com/).
2.  Нажмите **Download**.
3.  Запустите установщик и нажмите **Install**.
4.  После установки в правом нижнем углу (возле часов) появится иконка белой ламы. Это значит, ИИ готов к работе.

---

## 📁 ШАГ 2: Подготовка файлов проекта

1.  Если вы получили проект в архиве (ZIP):
    *   Нажмите правой кнопкой на архив -> **Извлечь всё...**
    *   Выберите папку (например, на Рабочий стол).
2.  **Проверьте содержимое:** зайдите в папку. Вы должны видеть там много файлов, включая `package.json`, `index.html` и папку `src`.

---

## 🐧 ШАГ 3: Работа в Терминале (Командная строка)

Не пугайтесь команд — мы просто дадим компьютеру пару указаний.

### Как открыть терминал правильно:
1.  Зайдите в папку с проектом.
2.  В верхней адресной строке проводника (там, где написан путь типа `C:\Users\Admin\Desktop\project`) удалите всё, напишите буквы `cmd` и нажмите **Enter**.
3.  Откроется черное окно. Это командная строка, уже настроенная на вашу папку.

### Проверка:
Введите по очереди эти команды, чтобы убедиться, что всё установилось:
*   `node -v` (должно написать что-то вроде `v22.12.0`)
*   `npm -v` (напишет число)

---

## 📦 ШАГ 4: Установка библиотек проекта

В папке проекта ещё нет тяжелых файлов кода (библиотек). Нужно их скачать одной командой.
В том же черном окне введите:
```cmd
npm install
```
*   **Что произойдет:** Компьютер скачает всё необходимое (React, карты, графики). Это займет 1-2 минуты. В папке появится огромная папка `node_modules`.

---

## 🧠 ШАГ 5: Загрузка "Мозга" (Нейросети)

Теперь нужно сказать Ollama, какую именно модель ИИ использовать. Мы используем оптимизированную версию LLaMA 3.

В терминале (черном окне) введите:
```cmd
ollama run llama3:8b-instruct-q2_K
```
*   **Внимание:** Начнется скачивание файла размером около 4.7 ГБ.
*   **Когда закончится:** Появится строка `>>> send a message`. ИИ работает!
*   **Нажмите `Ctrl + C`**, чтобы выйти из режима чата в терминале (но не закрывайте окно).

---

## 🚀 ШАГ 6: Финальный запуск!

Теперь запускаем сам сайт (дашборд). Введите команду:
```cmd
npm run dev
```
Вы увидите надпись:
`  ➜  Local:   http://localhost:5173/`

1.  **Скопируйте** эту ссылку или просто зажмите **Ctrl** и кликните по ней.
2.  Ваш браузер откроет систему AqylShahar!

## 🆘 ЭНЦИКЛОПЕДИЯ РЕШЕНИЯ ПРОБЛЕМ

### 1. ИИ в браузере пишет "Ollama offline" или не отвечает
Если сайт открылся, но при нажатии на "AI Анализатор" ничего не происходит:
1.  Проверьте, запущена ли Ollama (иконка в трее).
2.  Если не помогает, нужно принудительно разрешить браузеру общаться с ИИ. 
    *   Закройте Ollama (ПКМ по ламе в трее -> Quit).
    *   Откройте терминал (CMD) и вставьте эту команду:
        `set OLLAMA_ORIGINS=* && ollama serve`
    *   **Оставьте это окно открытым**. Попробуйте снова на сайте.

### 2. Ошибка "npm" или "node" не является внутренней командой
Вы установили Node.js, но не перезагрузили терминал. 
*   **Решение:** Закройте черное окно и откройте его заново через адресную строку папки (как описано в Шаге 3).

### 3. Ошибка "Port 5173 is already in use"
Это значит, у вас уже запущен проект в другом окне.
*   **Решение:** Найдите старое окно терминала и нажмите в нем `Ctrl + C`, либо просто используйте новую ссылку, которую предложит программа (например, `localhost:5174`).

### 4. Всё тормозит
*   ИИ — очень тяжелая программа. Во время его работы компьютер может шуметь. Постарайтесь закрыть лишние вкладки в браузере и тяжелые игры.

---

## 💡 Советы для тех, кто "скидывает" проект другу
Если вы передаете этот проект другому:
1.  **НЕ ПЕРЕДАВАЙТЕ папку `node_modules`**. Она весит сотни мегабайт. Друг сам её создаст командой `npm install`.
2.  **НЕ ПЕРЕДАВАЙТЕ папку `dist`**. Это временные файлы сборки.
3.  Просто заархивируйте все остальные файлы (src, public, package.json, vite.config.js и т.д.) и приложите эту инструкцию!
