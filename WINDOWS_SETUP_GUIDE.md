# 🚀 Инструкция: Запуск проекта AqylShahar на Windows

Эта инструкция предназначена для полной настройки проекта с "чистого листа" на любой системе Windows.

---

## 🛠 Шаг 1: Установка необходимых инструментов

Прежде чем запускать проект, нужно установить две основные программы:

### 1. Node.js (Среда для запуска JavaScript)
*   Перейдите на официальный сайт: [nodejs.org](https://nodejs.org/)
*   Скачайте версию **LTS** (Recommended for Most Users).
*   Запустите установщик, нажимайте везде "Next" (Далее). 
*   *Обязательно поставьте галочку "Automatically install the necessary tools" (если предложат).*

### 2. Ollama (Локальный искусственный интеллект)
*   Перейдите на сайт: [ollama.com](https://ollama.com/)
*   Нажмите "Download" и выберите Windows.
*   Установите программу. После установки в трее (возле часов) появится иконка ламы.

---

## 📂 Шаг 2: Подготовка проекта

1.  **Распакуйте архив** с проектом в удобное место (например, на Рабочий стол или в папку `C:\Projects`).
2.  **Зайдите в папку проекта**. Вы должны видеть там файлы `package.json`, `index.html` и папку `src`.

---

## 💻 Шаг 3: Настройка через Терминал

1.  В папке проекта нажмите правой кнопкой мыши на пустом месте и выберите **"Открыть в Терминале"** (Open in Terminal) или **"Открыть окно PowerShell здесь"**.
2.  Установите зависимости (библиотеки) проекта, выполнив команду:
    ```powershell
    npm install
    ```
    *Дождитесь завершения (появится папка `node_modules`).*

---

## 🧠 Шаг 4: Настройка ИИ (Ollama)

Чтобы ИИ в проекте заработал, нужно скачать конкретную модель, которую использует проект.

1.  В том же терминале (или в новом окне) введите:
    ```powershell
    ollama run llama3:8b-instruct-q2_K
    ```
    *Это скачает около 4.7 ГБ данных. Дождитесь конца. Когда появится строка ввода для общения с ИИ, можете закрыть это окно или нажать `Ctrl+D`.*

---

## 🚀 Шаг 5: Запуск проекта

1.  Вернитесь в терминал в папке проекта.
2.  Запустите сервер разработки:
    ```powershell
    npm run dev
    ```
3.  После запуска вы увидите ссылку, обычно это:
    [http://localhost:5173](http://localhost:5173)
4.  **Зажмите Ctrl и кликните по ссылке** (или просто скопируйте её в браузер).

---

## ⚠️ Возможные проблемы (Troubleshooting)

### 1. Ошибка "Ollama offline" в браузере
Если проект открылся, но ИИ не отвечает:
*   Убедитесь, что Ollama запущена (иконка ламы в трее).
*   Иногда нужно разрешить доступ браузеру к Ollama. Для этого закройте Ollama совсем и запустите её через терминал с переменной окружения:
    ```powershell
    $env:OLLAMA_ORIGINS="*"; ollama serve
    ```

### 2. Ошибка "npm: command not found"
*   Это значит, что вы не перезагрузили компьютер/терминал после установки Node.js. Закройте все окна терминала и откройте заново.

### 3. Медленная работа ИИ
*   ИИ работает на вашем процессоре/видеокарте. Если компьютер слабый, ответы могут появляться с задержкой. Модель `q2_K` выбрана как максимально легкая для обычных ПК.
